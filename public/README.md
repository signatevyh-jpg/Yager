# Ягерь — фронтенд мессенджера (PWA)

## Что это
Чистый фронтенд (HTML/CSS/JS, без сборщиков и фреймворков) с:
- экраном входа/регистрации по логину и паролю;
- списком чатов и окном переписки в стиле Telegram;
- установкой на iOS и Android как приложение (PWA).

Сейчас данные (пользователи, чаты, сообщения) хранятся только в
`localStorage` браузера — это заглушка вместо бэкенда, обмена
сообщениями между разными людьми/устройствами ещё нет.

## Как запустить локально
PWA (service worker) не работает при открытии файла напрямую (`file://`),
нужен локальный http-сервер. Например:

```
cd poyet
python3 -m http.server 8080
```

Откройте `http://localhost:8080` в браузере.

## Как установить на телефон
- **Android (Chrome):** откройте сайт → меню (⋮) → «Установить приложение» /
  «Добавить на главный экран».
- **iOS (Safari):** откройте сайт → кнопка «Поделиться» → «На экран Домой».

Оба варианта требуют, чтобы сайт был доступен по **https** (кроме
локальной разработки через `localhost`) — просто выложите папку на
любой статический хостинг (Vercel, Netlify, GitHub Pages, Cloudflare Pages
и т.п.).

## Структура проекта
```
poyet/
  index.html          — разметка приложения
  manifest.json        — манифест PWA (имя, иконки, цвет темы)
  sw.js                 — service worker (офлайн-кэш, установка)
  css/style.css         — все стили
  js/config.js          — ЕДИНАЯ точка переключения на реальный бэкенд
  js/api.js             — весь обмен данными (сейчас mock, см. ниже)
  js/mock-data.js        — тестовые "собеседники" для демо-режима
  js/auth.js             — экран входа/регистрации
  js/app.js               — список чатов + окно переписки
  icons/                  — иконки для главного экрана iOS/Android
```

## Как подключить бэкенд
1. Откройте `js/config.js`, поставьте `USE_MOCK: false` и укажите
   `API_BASE_URL` / `WS_URL` вашего сервера.
2. Реализуйте на сервере эндпоинты, перечисленные в комментарии в
   начале `js/api.js` (register/login/chats/messages + WebSocket
   события `message` / `typing` / `presence`).
3. Допишите тело функций в объекте `real` внутри `js/api.js` —
   `auth.js` и `app.js` их уже вызывают, их менять не нужно.

### Что обязательно нужно на сервере (для реальной безопасности)
- Хэширование паролей на сервере (bcrypt/argon2), а не в браузере.
- HTTPS везде, включая WebSocket (`wss://`).
- Токены сессии (JWT или подобное) с истечением срока действия.
- Проверка прав доступа: пользователь должен получать сообщения только
  тех чатов, участником которых он является.
